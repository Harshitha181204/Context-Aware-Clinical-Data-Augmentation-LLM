# Context-Aware Clinical Data Augmentation using Advanced Generative LLM

## Overview
This project is a Final Year B.Tech project that generates context-aware synthetic clinical data using Advanced Generative Large Language Models (LLMs).

## Features
- User Authentication
- Patient Management
- Medical Record Management
- Clinical Data Augmentation
- Result Visualization
- Database Integration

## Technologies Used
- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite/MySQL
- Large Language Models (LLMs)

## How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Apply migrations:
   python manage.py migrate

3. Start the server:
   python manage.py runserver
